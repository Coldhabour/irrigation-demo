# Security and privacy

This directory is a self-contained publication candidate. It was created independently of the private application's runtime. Only new prose, a small illustrative browser demo, synthetic fixtures, a newly authored spreadsheet and images of those artifacts belong in it.

## Data provenance

Sakura Residence Demo Project is fictional. All quantities, sector names, generic material identifiers and hydraulic inputs were invented for this case study. There are no contact details, prices, coordinates, real project files or manufacturer curves. The demo uses a documented JSON shape created for this portfolio, not a `.LND` representation.

## Source boundary

Private source was inspected to substantiate high-level descriptions, but no application source files, proprietary algorithms, catalog mappings, schema dumps, executables or company templates are included. Newly written demo code validates fictional fixtures, groups exact identifiers/units and screens eight independently invented pump curves using generic interpolation. Plots, a simplified system model and browser printing use only invented data. No company mappings or real manufacturer catalogs are used.

## Local behavior

The demo uses local files and browser memory. There are no external fonts, scripts, trackers, network requests, credentials, accounts, browser persistence or connections to operational storage. Downloads are explicit local actions. The workbook is a synthetic snapshot and does not change when the browser demo is edited.

## Ownership and review

Removing confidential data does not establish a right to publish employer-related material. The author must confirm permission to describe the work and verify their individual contribution before publication. No license to the private application, company assets or third-party catalogs is granted. No open-source license has been assigned to the publication candidate pending that review.

## Release scope

Only this directory's reviewed files should be copied into a fresh repository. Do not reuse the private repository, its history, build output or portable package. Any change after review requires a new content and metadata check. Automated scans reduce accidental disclosure but cannot establish ownership or detect every confidential fact.
